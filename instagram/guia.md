# Guía de contenido — Instagram del Dr. Andrés León

## Objetivo único

Cada pieza lleva a **agendar una valoración** (`contenido/cta.md`).
Estrategia: **educar para bajar el miedo**, no vender.

## Formatos

| Formato | Tamaño | Plantillas |
|---|---|---|
| Carrusel (principal) | 1080×1350, 5 a 8 slides | `01-portada` → intermedias → `07-cierre-cta` |

El tema se cambia con la clase del `<body>`: `claro`, `tinta`, `hielo`.

## Ritmo de un carrusel

Alterna **tinta → claro → tinta → claro → … → tinta (CTA)**. Estructura base de 6–7 slides:
1. **Portada**: pregunta o idea que el paciente reconoce.
2. **Qué pasa** (explicación simple).
3. **Señales / mito**.
4. **Dato propio** o principio (sin cifras inventadas).
5. **Enfoque**: la frase que se queda.
6. **CTA**: agendar la valoración.

## Caption

- Primera línea: el gancho, sin emojis, < 12 palabras.
- Cuerpo: 60–120 palabras, frases cortas, tuteo.
- Nota de prudencia si habla de síntomas.
- Cierre: un solo CTA de `contenido/cta.md`.
- Hashtags (5 a 8): `#endodoncia #endodoncistabogota #tratamientodeconductos #saludoral #odontologiabogota #antiguocountry #cuidadodental #dolordemuelas`  *(sin espacios; el listado es orientativo, elegir 5–8)*
- Línea final interna: **Validar con el doctor:** …
